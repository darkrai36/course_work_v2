# Система детектирования подозрительной активности в реальном времени
Данный проект представляет собой высоконагруженную систему для мониторинга и выявления мошеннических действий пользователей (фрода) в потоке событий в режиме реального времени.

Проект разработан в рамках курсовой работы: *"Разработка системы детектирования подозрительной активности пользователей в режиме реального времени на основе анализа потока событий"*.

## Архитектура и cтек технологий
Система спроектирована с использованием современных паттернов потоковой обработки данных.

* **Java 17 & Spring Boot 3** — ядро приложения.
* **Apache Kafka** — отказоустойчивый брокер сообщений. Принимает непрерывный поток сырых событий (50-100 RPS) от генератора нагрузки.
* **Redis** — In-Memory хранилище. Используется структурой `Sorted Set` для реализации паттерна "Скользящее окно" (Sliding Window) с автоматическим TTL на 5 минут. Позволяет консьюмеру хранить State без риска OutOfMemory и потери данных при рестарте.
* **ClickHouse** — колоночная аналитическая база данных. Выступает в роли "холодного архива", куда параллельная группа консьюмеров сохраняет 100% сырого трафика для последующего SQL-анализа.
* **WebSocket (STOMP)** — протокол для двунаправленной связи с браузером, обеспечивающий моментальную доставку алертов на пульт (дашборд) безопасника без перезагрузки страницы.

## Детектируемые сценарии атак (Паттерны)

Модуль аналитики `AnalyzerService` обрабатывает поток "на лету" и выявляет следующие типы фрода:
1. **Brute-force (Перебор паролей):** Более 5 попыток `LOGIN` от одного пользователя за 1 минуту.
2. **Carding (Проверка карт):** Более 3 событий `PAYMENT` за 2 минуты (характерно для проверки краденых карт мелкими транзакциями).
3. **Account Takeover (Угон аккаунта):** Смена пароля/профиля (`PASSWORD_CHANGE` / `PROFILE_UPDATE`), за которой в течение короткого времени следует платеж.
4. **Distributed Attack:** Активность одного пользователя с более чем 3-х уникальных IP-адресов за 5 минут (использование прокси/VPN).

## Быстрый старт (Инструкция по запуску)

### Требования:
* Установленный Docker и Docker Compose
* Установленный JDK 17 (или выше)

### Шаг 1: Запуск инфраструктуры
Для работы системы необходимы Kafka, Zookeeper, Redis и ClickHouse. Все они настроены в Docker.
В корневой папке проекта выполните команду:
```bash
docker-compose up -d
```
Дождитесь скачивания образов и запуска контейнеров. Проверить статус можно командой 
```bash
docker ps
``` 
(должно работать 4 контейнера).

### Шаг 2: Запуск Spring Boot приложения

Запустите основной класс приложения SentinelCoreApplication через вашу IDE (IntelliJ IDEA / Eclipse) или используя Gradle:
Bash

```bash
./gradlew bootRun
```

При запуске система автоматически создаст необходимые таблицы в ClickHouse (движок MergeTree), а также начнет генерировать поток из 50-100 событий в секунду (как обычных пользователей, так и имитации действий злоумышленников).

### Шаг 3: Просмотр результатов (Дашборд)

Откройте браузер и перейдите по адресу: http://localhost:8080

На дашборде вы увидите:

- Real-time монитор: Сюда по WebSocket будут в реальном времени падать красные алерты о выявленных хакерах.

- Кнопка "Запросить аналитику": Выполняет агрегирующие SQL-запросы к ClickHouse (подсчет общего числа событий, группировка по типам и вывод Топ-3 самых активных IP), демонстрируя работу с большими объемами исторических данных.

### Остановка проекта

Для корректного завершения работы остановите Java-приложение и выключите контейнеры командой:
Bash
```bash
docker-compose down
```
